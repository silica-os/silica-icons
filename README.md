Silica icons: apps, folders and files, system symbols. All original, drawn for the
project.

## Structure

```
apps/      app icons, layered: the shell applies shape, shadows, glass and themes
files/     folders, file types, Trash, Dock controls: layered, free-form
badges/    badges overlaid on file icons (alias, locked, unreadable, cloud)
symbols/   system glyphs (Control Center, menu bar, settings, toolbars): monochrome,
           vector, multiple weights, colored by the theme
fonts/     Silica Symbols icon font (Light, Regular, Semibold), codepoints, Flutter IconData
tools/     export from the design file, icon font build (tools/symbols-font), package build
docs/      specifications: icon format, grid, themes
```

The system symbols are also an icon font for Sketch and Flutter: see the Font section of
[`docs/symbol-format.md`](docs/symbol-format.md).

## Model

- App icons contain neither shape nor shadow: the developer supplies a background and
  up to four groups of SVG layers on the 1024 grid; the shell clips them with the mask
  (body 824, smooth corners r 215), adds border, shadows and glass and generates the
  themes Default, Dark, Clear Light, Clear Dark, Tinted Light, Tinted Dark.
- Icons without layers (an existing freedesktop theme) are reduced to the 600 keyline and
  placed on a neutral base.
- Format specification: [`docs/icon-format.md`](docs/icon-format.md).

## Design source

`design/app-icons.sketch` is the design source (pages Grid, Icons, Grid Check,
Showcase, Showcase Files, Showcase Desktop, Dynamic Icons). The SVG layers of each icon
are exported from there; the exported files are the authoritative ones for the build.
The Trash (empty and full) is the exception: it is generated by `tools/trash/` (a 3D model in
Python, `full.py` writes both icons) and is not in the design file.

## Tools

```
python3 -m venv venv && venv/bin/pip install pillow resvg-py
venv/bin/python tools/compose.py --fonts <folder with Inter> --out build/sheet-light.png
venv/bin/python tools/compose.py --dark --fonts <folder with Inter> --out build/sheet-dark.png
```

`compose.py` recomposes every icon from its layers as the shell would and writes a check
sheet (layers only: symbols, text and tints of file and folder thumbnails belong to the
thumbnail generator in silica-desktop).

## Contents

- `apps/`: 18 apps (apps, calculator, calendar, clock, disks, fonts, mail, mission-control, mustache,
  notes, password-manager, photo-viewer, photos, reminders, screenshot, settings, terminal,
  text-editor) with dark variants and a rendered `icon.png` / `icon-dark.png`; calendar and clock
  are dynamic.
- `files/`: one folder in three layers (back, middle sheet shown when it has items, front), one generic file in
  two layers (back and folded front), 5 volumes (internal disk,
  external, network server, mounted disk image, optical disc), empty and full Trash. For file icons the side is the full
  canvas: sheets, folders, volumes and Trash fill almost all of it, as in the reference (document keyline 684 × 904, folder 956 × 776,
  volume 944 × 583, Trash 656 × 824).
- `badges/`: alias, locked, unreadable and cloud, in light and dark, with the composition
  rules in `badges.json`.
- `symbols/<weight>/`: 324 symbols in 11 categories and three weights (`light`, `regular`,
  `semibold`), generated by `tools/symbols/symbols.py` (`export_svg.py --check` verifies
  that the SVGs match the source). Specification:
  [`docs/symbol-format.md`](docs/symbol-format.md); design source `design/symbols.sketch`.
